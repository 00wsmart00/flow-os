# 数据与知识产权合规

## 不可突破的边界

FlowOS 的开发、测试、演示、截图和文档只能使用合成数据。

严禁复制、导出、推断或复用以下内容：

- 雇主或客户的订单、库存、采购、供应商或客户记录；
- 企业源代码、数据库结构、字段名、状态码、API 文档、提示词或专有业务规则；
- 凭证、访问令牌、个人数据、保密文档或生产日志。

不得将雇主或客户资料提交给第三方 AI 服务。公开资料或个人创作资料在使用前仍需检查许可条件和保密要求。

## 开发控制

- 合成测试数据使用明显的 `SYN-` 前缀和虚构名称。
- `.env` 必须被 Git 忽略；`.env.example` 只包含本地占位值。
- 本仓库禁止保存生产快照和数据库转储。
- 日志默认不记录请求正文和敏感信息。
- 未来的任何种子数据命令都必须拒绝在生产环境运行。
- 依赖项和生成资产在分发前需要完成许可证审查。

## 未来生产环境要求

在处理经过授权的真实业务数据前，必须实现租户隔离、最小权限、身份认证与授权、加密、密钥管理、保留与删除策略、审计日志、备份控制、事件响应、数据处理协议，以及适用司法辖区的隐私审查。

## 审查清单

合并变更前，应确认其中的数据、示例、截图、结构、命名和规则均为独立创建的合成内容。如果来源无法确认，不得提交，并应升级审查。
