# FlowOS AI V0.1 产品需求文档

## 目标

FlowOS AI V0.1 用于验证一条适合中小型服装制造企业的、小范围且可解释的工作流：查找销售订单、计算物料库存缺口，并生成可供审核的采购建议草稿。

本文描述 V0.1 的目标状态。当前仓库已完成有边界的订单查询、基于显式 BOM 版本的物料需求展开，以及基于显式库存快照的首个确定性缺口分析增量。

## 用户与问题

初始用户是运营或采购协调人员。他们需要更快地判断一张销售订单能否由现有库存满足。系统应减少重复查询和手工计算，但不能隐藏假设，也不能自行做出具有约束力的采购决定。

## 目标流程

1. 用户通过受限字段查询销售订单。
2. 系统通过稳定的 API 契约展示订单需求。
3. 纯领域计算将需求与合格库存及占用进行比较。
4. 系统解释每项短缺及其输入依据。
5. 系统生成采购建议草稿，但不提交采购订单。
6. 人工审核、编辑、导出或丢弃草稿。

## V0.1 验收结果

- 订单查询有明确边界且结果确定，不允许任意 SQL。
- 缺口计算是经过单元测试的纯业务逻辑。
- 采购输出被明确标记为无约束力的草稿，并具有审计记录。
- API 契约使用 Pydantic 模型，与持久化模型分离。
- 所有测试和演示数据都是明确标识的合成数据。

## 不在范围内

- 直接创建采购订单或向供应商发送消息
- 面向企业数据库的通用聊天查询
- 自主决策或绕过审批
- 完整的权限控制、SSO、多租户、预测和优化
- 在基础里程碑中接入 LLM

## 当前里程碑

当前已交付代码仓库基础、订单查询 API、产品与订单行、物料与版本化 BOM、库存快照、物料需求与缺口纯计算、版本化迁移和合成测试数据。采购建议及更完整的供应资格规则仍将在后续独立评审的增量中完成。
